# Бойды — моделирование стайного поведения

**Автор:** Черенков Сергей Сергеевич

**Группа:** ПИ25-1

## Описание проекта

Программа моделирует поведение стаи птиц по алгоритму «Бойды» Крейга Рейнольдса.
Каждый бойд видит только ближайших соседей и подчиняется трём правилам:
разделению, выравниванию и сплочению.

Лабораторная работа №2 «Сложная анимация», задание «Бойды».
